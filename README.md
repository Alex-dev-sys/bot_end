# ⚔️ PvP End Timer Bot v2.0 Pro

Продвинутый Telegram бот для уведомлений о PvP в End.

## ✨ Новые возможности v2.0
- **Интерактивное меню**: Кнопки для управления вместо команд.
- **Таймер**: Показывает точное время до начала или конца PvP.
- **Админка**: Рассылка объявлений всем игрокам.
- **Авто-расписание**: Уведомления приходят автоматически по времени.

## 🚀 Установка и Обновление

### 1. Настройка
В файле `pvp_bot.py`:
- `BOT_TOKEN`: Ваш токен от @BotFather
- `ADMIN_ID`: Ваш цифровой ID Telegram (для доступа к `/broadcast`)

### 2. Запуск на VPS

**Вариант с авто-перезапуском (рекомендуется):**
```bash
# Установка PM2 (если нет)
npm install -g pm2

# Запуск
pm2 start pvp_bot.py --interpreter python3 --name pvp-bot

# Просмотр логов
pm2 logs pvp-bot
```

**Обычный запуск:**
```bash
nohup python3 pvp_bot.py > bot.log 2>&1 &
```

## 📱 Команды и Кнопки

### Меню (Кнопки)
- **📊 Статус**: Показать, идет ли сейчас PvP и сколько осталось времени.
- **📅 Расписание**: Показать таблицу времени.
- **🔔 Подписаться / 🔕 Отписаться**: Управление уведомлениями.

### Админ-команды
- `/broadcast <текст>` — Отправить сообщение всем подписчикам.
  *Пример: `/broadcast ⚠ Сервер уходит на техработы!`*
